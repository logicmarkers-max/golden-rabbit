# Golden Rabbit - Premium Crackers Shop 🐰🎆

A modern, responsive React website for Golden Rabbit online crackers shop. Built with cutting-edge technologies to provide an exceptional user experience.

![Golden Rabbit Banner](https://img.shields.io/badge/Golden%20Rabbit-Premium%20Crackers-gold?style=for-the-badge&logo=sparkles)

## 🌟 Features

- **Modern UI/UX**: Stunning gradient designs with glassmorphism effects
- **Responsive Design**: Optimized for all devices and screen sizes
- **Interactive Components**: Smooth animations and hover effects
- **Product Showcase**: Dynamic product filtering and categories
- **Premium Design**: Professional layout with attractive color schemes
- **Fast Performance**: Built with Vite for lightning-fast development

## 🛠️ Technology Stack

- **Frontend**: React 18 + Vite
- **Styling**: CSS3 with modern features (Grid, Flexbox, Gradients)
- **Fonts**: Google Fonts (Cinzel + Inter)
- **Icons**: Emoji-based icon system
- **Development**: Hot Module Replacement (HMR)

## 🚀 Quick Start

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. **Install dependencies**
   ```bash
   npm install
   ```

2. **Start development server**
   ```bash
   npm run dev
   ```

3. **Open your browser**
   ```
   http://localhost:5173
   ```
